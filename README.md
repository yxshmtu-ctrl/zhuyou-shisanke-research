## 性质与用途
- 祝由科为古代符咒治病方术文献（托名轩辕黄帝），属前科学时期观念
- 本整理供**中医史、民俗学、宗教文献学、本草学史**研究参考
- 书中"化灰/符水/佩符"等方法**不具备现代医学效力**，不提供医疗建议

## 主要成果
1. 全书 104 页 OCR 文本（繁体竖排经算法重排为列读序）
2. 结构框架：叙文→名目戒条→书符仪轨→主治总诀→三部病符→分科符→章次→集方→葛仙翁部
3. 文献学观察：版本性质、四源混编（道教科仪/密教咒音/符禁/本草）、"十三科"名义、医学史可考汤引

## 已知局限
- OCR 为初校稿，错讹（尤以密教梵音咒语、符旁小字为甚），**引用务必回查原书影印 PDF**
- 符箓图形本体无法 OCR，仅提取旁注文字
